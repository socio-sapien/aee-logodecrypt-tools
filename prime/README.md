# AEE × LOGODECRYPT PRIME
## Inspect the sentence. Preserve the record. Explore the alternative.
Nathaniel Michael Jaffe-Norris · local experimental toolkit · v1.0

A one-file Python tool for source-preserving text inspection, paired-record review and explicitly labelled textual transformations. Six synthetic demonstrations below were generated by the actual module. They are not customer records, hidden-intent discoveries or a validation benchmark.

## Interactive demonstration

Explore the live [nine-scene PRIME demonstration floor](https://socio-sapien.github.io/aee-logodecrypt-tools/prime/demo-environment/), then use [its guide](demo-environment/README.md) for local rebuilding and scope. The page is a static presentation of exact output from the deterministic core; it makes no external model calls and contains only synthetic data.

## What it makes
- Cue ledgers: exact quotes, character offsets, modal/negation/role/flow candidates.
- Source comparison: numeric multiset and curated polarity changes.
- Disclosure checklist: matched cues versus no cue match in the excerpt.
- Script/control lens: mixed scripts and invisible format codepoints.
- Creative key: bounded stipulated letter associations and labelled lexical counterfactuals.
- Custody record: exact original plus deterministic unsigned SHA256 receipt.

## Run it
```sh
python aee_logodecrypt_prime.py --demo
python aee_logodecrypt_prime.py --self-test
python aee_logodecrypt_prime.py --file candidate.txt --context source.txt
```

Python 3.10+; standard library; no model/API, login or network call. The core module is a new consolidation, not certified conformance to every historical AEE/LOGODECRYPT edition.

## Evidence boundaries
- 36 local implementation checks passed; six synthetic demos executed. No independent accuracy, security, legal or enterprise validation is claimed.
- Generated associations/counterfactuals are not recovered truth, intent, culpability or missing verbatim speech.
- A keyword hit does not establish a substantive clause; no cue match does not establish its absence outside the excerpt.
- Unsigned hashes are not Ed25519 signatures, trusted identity or proof of honesty.
- Source comparison is narrow: no semantic entailment, role binding or general fact-checking.
- No corpus/evidence specimens, hidden instructions, endpoint telemetry or personal data are included.

## Proposed application families
Source-fidelity regression checks; disclosure-review worksheets; Unicode boundary inspection; authorized evaluation fixtures; evidence-first creative writing. These are exploratory use cases, not validated market demand or existing framework integrations.
