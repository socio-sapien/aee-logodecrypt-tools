# Controlled PRIME comparison and GitHub Actions battery

The paired CLI runs were executed on a local machine using GitHub Copilot CLI; they were not seven independently assigned GitHub agents. `base.*` and `audited.*` preserve their prompts, output, errors, elapsed process times and exit codes. These are one observation per condition; the two prompts differ because the audited condition explicitly asks the model to call three tools. Both runs used automatic model selection, reported GPT-6 Luna, and correctly identified the same three grouped differences and unchanged deployment day. In this sample the audited run was slower. Two audit-related calls rejected their arguments, so this is not a full-battery agent comparison and does not establish improvement.

The Actions workflow runs the repository's current PRIME text instrument, full-source deterministic seven-role chain, local preflight, role lexicons, a caller-supplied four-by-four evidence matrix, and synthetic role scenarios. It uploads complete machine-readable inputs, receipts, calculations and outputs. It does not run independent Copilot agents in GitHub, all historical AEE instruments, or live automated repair. Inputs are synthetic. The AEE UI dashboard is a qualitative audit. Cue counts and formulas are mechanical; label interpretations, causal claims and real-world accuracy are not established by this demo. No provider credentials or paid service calls are used by this workflow.
