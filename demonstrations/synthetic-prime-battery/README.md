# Synthetic PRIME battery

Run a single offline demonstration combining the text instrument, deterministic seven-role source chain, exact-match lexical ledger, simulated preflight, caller-supplied evidence matrix, and seven synthetic role fixtures:

```sh
PYTHONPATH=. python demonstrations/synthetic-prime-battery/run_battery.py --output /tmp/prime-synthetic-battery.json
```

Use a new output path; the script refuses to overwrite a file. The JSON includes the complete example texts and outputs. The inputs are synthetic and the simulation does not execute the proposed operation. The role checks are deterministic routines, not independent agents. The matrix classification is supplied by the caller, not an independently validated remedy. Literal cues and formula labels do not establish accuracy, intent, security, causation or effectiveness. Timing measures this local run only and is not a latency guarantee. This is not a live model test or a benchmark of every historical tool.

Adapted from the existing public `prime/github-battery-proof` branch, commit `7a825c668739ab97ab9a1c85a55a68425ed39d26`. The original paired CLI logs and the branch-specific workflow are intentionally not included. Existing PRIME Pages content and workflow are unchanged.
